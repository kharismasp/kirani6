# Kirani — Operations + BODMAS | TKA Geometry & Measurement

Teacher-version offline interactive lesson site.

## Open
1. Extract this ZIP.
2. Open `index.html` in a modern browser.
3. No server, installation, account, internet connection, CDN, or API is required.

## Teacher navigation
- `← Back` = previous task/page/section without intentionally clearing completed progress.
- `PASS →` = teacher bypass for the **current task**. It skips forward, does **not** reveal the answer, and does **not** count as independent mastery.
- The cover menu can jump directly to **Warming Up**, **Lesson with Miss**, or **Latihan Mandiri**.

## Lesson order
Cover → Warming Up → Back-to-Zoom screen → Lesson with Miss → Latihan Mandiri → Finish / summary.

## Notes
- Progress is stored locally in the browser with `localStorage`.
- Selected independent challenges expose **Try a Parallel One** only after the original challenge is completed.
- All assets are local and bundled in this folder.
